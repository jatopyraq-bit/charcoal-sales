charcoal-sales/

Файлы:
- index.html — приложение
- manifest.webmanifest — PWA-манифест
- sw.js — офлайн-кэш

Как запустить:
1) Для быстрого теста откройте index.html в браузере на компьютере.
2) Для установки как приложения на iPhone разместите папку на HTTPS-хостинге (например, GitHub Pages, Netlify или Cloudflare Pages), затем откройте сайт в Safari → Поделиться → На экран «Домой».
3) Данные сохраняются в localStorage браузера. Кнопка «Резерв» скачивает JSON-копию.

Важно: это первая рабочая версия интерфейса. Она содержит данные из предоставленного Excel и повторяет ключевую логику: продажи, поставки, себестоимость с логистикой/разгрузкой, безнал 3%, оплачено/X, красная строка, расходы и месячный отчёт.
